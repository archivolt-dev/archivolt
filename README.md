# Archivolt

[![ci](https://github.com/archivolt-dev/archivolt/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/archivolt-dev/archivolt/actions/workflows/ci.yml)

Living architecture documentation for Spring (Java/Kotlin) systems: static analysis builds a graph of
endpoint → component → repository → entity → table/column in Neo4j, exposes it to AI agents over MCP
and to people through a web portal. Developed as part of an MSc thesis (PJATK).

**Status:** work in progress, no release yet.
